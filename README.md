
## Hi there

Curiosity is what pulled me into software relatively late in life, and I've been building ever since.

I like creating software that's genuinely useful. I'm a strong believer in individual agency, and I think open source is one of the best ways to preserve it., I believe great software should earn its users through the problem it solves, not by forcing paywalls.

I started my career maintaining fire alarm systems, which shaped how I think about engineering. I prefer straightforward, reliable systems over unnecessary complexity.

When I'm not writing code, I'm probably reading random blogs through Hacker News, learning about space and engineering, hitting the gym or planning the next project.
